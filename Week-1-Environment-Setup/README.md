# Week 1 – Environment Setup

## Objective
The goal of Week 1 was to build a secure virtual cybersecurity lab using VMware Workstation Pro. This environment serves as the foundation for all practical exercises completed during the internship.

## Tasks Completed

- Installed VMware Workstation Pro
- Created a Kali Linux virtual machine
- Created an Ubuntu virtual machine
- Configured NAT and Host-Only network adapters
- Verified internet connectivity on both virtual machines
- Tested communication between Kali Linux and Ubuntu using ping
- Installed VMware Tools (open-vm-tools)
- Created a "Clean Install" snapshot for future recovery

## Skills Learned

- Virtualization fundamentals
- VMware Workstation configuration
- Linux virtual machine deployment
- Network configuration (NAT & Host-Only)
- Basic Linux networking commands
- Connectivity testing
- Snapshot management
