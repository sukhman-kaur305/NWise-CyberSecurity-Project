# Week 2 – Network Security

## Objective

The objective of Week 2 was to understand how devices communicate across a network by using industry-standard security tools to discover hosts, identify running services, capture network traffic, and analyze common network protocols. :contentReference[oaicite:0]{index=0}

---

## Tools Used

- Kali Linux
- Ubuntu Desktop
- VMware Workstation Pro
- Nmap
- Wireshark

---

## Lab Activities

### 1. Network Connectivity

- Identified the Ubuntu VM IP address.
- Verified connectivity between Kali Linux and Ubuntu using ICMP ping.

### 2. Network Discovery with Nmap

Performed network reconnaissance using Nmap to:

- Discover active hosts
- Identify open ports
- Detect running services
- Perform service version detection

### 4. Network Traffic Analysis

Observed and analyzed:

- ARP requests and responses
- ICMP Echo Requests and Replies
- TCP three-way handshake
- SSH encrypted communication
- DNS traffic (if generated)

Compared packet captures with Nmap scan results to understand how network discovery relates to actual network traffic. :contentReference[oaicite:1]{index=1}
