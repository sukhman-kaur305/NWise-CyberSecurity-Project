## Why Learn AWS?

Modern organisations increasingly rely on cloud computing to deliver **scalable, secure, reliable, and cost-effective IT services**.

Instead of maintaining and managing expensive on-premises infrastructure, businesses can use cloud platforms such as AWS to:

* Host applications
* Store and manage data
* Deploy services globally
* Scale resources based on demand
* Improve availability and reliability
* Implement security and access controls

**Amazon Web Services (AWS)** provides a broad range of cloud services covering areas such as:

* Computing
* Storage
* Networking
* Databases
* Security
* Monitoring
* Artificial Intelligence and Machine Learning

AWS enables organisations to build, deploy, and manage applications efficiently while supporting high levels of availability, scalability, and security.

AWS is widely used by:

* Cloud Engineers
* Cybersecurity Analysts
* Systems Administrators
* DevOps Engineers
* Software Developers
* IT Operations Teams

Learning AWS provides valuable knowledge of cloud technologies and develops skills that are highly relevant across the **IT, cloud computing, and cybersecurity industries**.

## Key AWS Concepts Learned

### ☁️ Cloud Computing

Learned the fundamentals of cloud computing and how organisations can access IT resources over the internet without maintaining all infrastructure on-premises.

### 💻 Compute

Learned about AWS compute services, including **Amazon EC2**, which provides scalable virtual servers in the AWS Cloud.

### 🗄️ Storage

Developed an understanding of AWS storage solutions and how organisations can securely store and manage data in the cloud.

### 🌐 Networking

Learned foundational AWS networking concepts and how cloud resources can communicate securely within an AWS environment.

### 🛢️ Databases

Explored the purpose of AWS database services and how organisations can use managed database solutions to support applications.

### 🔐 Security and Identity

Learned about AWS security principles, identity and access management, and the importance of controlling access to cloud resources.

### 🛡️ Shared Responsibility Model

Gained an understanding of how security responsibilities are shared between **AWS and the customer**. AWS is responsible for security **of** the cloud, while customers are responsible for security **in** the cloud, depending on the services they use.

### 💰 AWS Pricing and Cost Management

Learned about AWS pricing models and the factors that influence cloud costs, including:

* Compute
* Storage
* Data transfer
* Pay-as-you-go pricing
* Reserved capacity and commitment-based savings
* Cost monitoring and management

### 📈 Scalability and Reliability

Learned how AWS helps organisations build scalable and highly available applications using cloud-based services and infrastructure.

## AWS Services and Tools Explored

During the AWS Cloud Practitioner Essentials training, I learned about several AWS services and concepts, including:

* **Amazon RDS** – Managed relational databases

* **AWS Well-Architected Framework** – Best practices for designing cloud workloads
